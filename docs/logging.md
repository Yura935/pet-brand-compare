# Журнал

Кожен запис — один рядок:

`YYYY-MM-DDTHH:mm:ss.sss+HH:mm LEVEL текст`

Час локальний, зі зміщенням часового поясу. Наприклад: `2026-10-26T15:51:08.466+02:00`.

Рівні: `INFO`, `WARN`, `ERROR`.

Журнал пишеться в консоль і у файл `data/app.log`. Файл з’являється під час роботи сервера і в git не входить.

Кожен `WARN` і `ERROR` також з’являється на вкладці Issues: Type (`warn` або `error`), статус із тексту журналу, фрагмент і посилання на товар, якщо воно є.

Російська на картці пишеться як `Російська мова на сторінці`, разом із адресою товару і початком речення, де знайдено слово. Відгуки покупців і текст на фото упаковки в цю перевірку не входять.
