# Порівняння брендів

Локальна сторінка збирає картки товарів з [Petslike](https://petslike.ua/) і [Pethouse](https://pethouse.ua/ua/), рахує їх по брендах і трьох статусах і віддає xlsx.

Повний опис правил: `docs/superpowers/specs/2026-10-26-site-compare-design.md`.

## Що потрібно

- Node.js 22 або новіший
- Встановлений Google Chrome. Petslike відхиляє звичайний запит і вбудований браузер Playwright, тому збір іде через Chrome
- Мережа. Повний каталог — близько 35 тисяч карток, збір триває від десятків хвилин до кількох годин

## Запуск

```bash
npm install
npx playwright install chromium
npm start
```

Відкрийте http://localhost:3000.

`npx playwright install chromium` ставить запасний браузер. Робочий шлях — уже встановлений Chrome.

Кнопка «Аналізувати сайти» починає збір. Оновлення сторінки його не зупиняє. «Завантажити xlsx» стає активною після завершення. Файл називається `porivnyannya-saitiv-YYYY-MM-DD.xlsx` і лежить у `data/`. Зразок на робочому столі програма не змінює.

Якщо довідник брендів або список карток не прочитався, кнопка стає «Продовжити» і повторює зупинений крок. Уже пораховані картки повторно не відкриваються.

Порт змінюється змінною `PORT`.

## Перевірки

```bash
npm test
```

Перевірки читають збережені фрагменти сторінок і не ходять по живому каталогу.

## Як влаштовано

Один процес Node віддає сторінку і веде збір.

Сервер написаний на TypeScript і запускається через `tsx` без окремого кроку збірки. Перевірка типів: `npm run typecheck`.

| Файл | Роль |
| --- | --- |
| `src/server.ts` | Сторінка, `/api/job`, завантаження xlsx |
| `src/job.ts` | Черга збору, збереження стану кожні 50 карток |
| `src/browser.ts` | Chrome через Playwright, пауза між запитами |
| `src/lists.ts` | Довідники брендів і адреси карток із sitemap |
| `src/classify.ts` | Статус однієї картки: в наявності, немає, знято |
| `src/brands.ts` | Ключ бренду, псевдоніми, лічильники |
| `src/xlsx.ts` | Аркуш `Аркуш1` у формі зразка |
| `src/types.ts` | Спільні типи статусу, бренду і стану збору |
| `src/log.ts` | Журнал у консоль і `data/app.log` |
| `public/` | Сторінка українською |
| `aliases.json` | Пари назв одного бренду. Зараз: «Клуб 4 Лапи» і «Club 4 Paws» |
| `test/` | Перевірки без живого обходу |

Стан збору лежить у `data/job.json`. Журнал — у `data/app.log`. Обидва в git не входять. Формат журналу: `docs/logging.md`.
